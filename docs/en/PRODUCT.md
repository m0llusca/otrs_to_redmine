# Product brief — OTRS ↔ Redmine

One flow: escalate or link from the ticket → store the Redmine ID → sync both ways.

| Role | Decision |
|------|----------|
| Product | Miscellaneous menu (not a queue); DF + internal article. |
| Backend | Ticket Event + SysConfig (CE without Business Invoker). |
| Operator | Service API key, visible errors, idempotent create/link. |
